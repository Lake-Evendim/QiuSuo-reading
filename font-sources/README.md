# 正文来源名称字体

已采用G「斜切未来」。当前中文：得意黑 Smiley Sans，原生斜切字形。
https://github.com/atelier-anchor/smiley-sans/releases/tag/v2.0.1

当前英文：Syne，固定实例化为700字重。
https://fonts.google.com/specimen/Syne

来自作者官方发布与Google Fonts官方字体服务，授权保存在SmileySans-OFL.txt和Syne-OFL.txt。完整字体作为可复现的源文件；网页只加载字体更新.py生成的woff2来源名称子集。子集内部名称为Jianwei Publisher Chinese／Latin，避免保留字体名限制。两款字体仅用于正文页公众号名称。桌面22px／手机21px，行高1.65、字距.01em，与G预览一致。

之前的文楷、毛笔楷、Cormorant与Space Grotesk原件及授权保留用于回退。其余候选的说明与字体来源见type-lab/README.md。
