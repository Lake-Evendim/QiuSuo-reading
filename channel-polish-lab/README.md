# 公众号原作微调预览

本轮尚未采用，正式 prototype 未修改。以用户认可的 DG1 为基础，保持纯白底、绿/褐实色与浅色的收录语义、现有字体、分类横幅和文章区底色。

入口：http://127.0.0.1:8807/channel-polish-lab/?mode=polish#channels

标题旁可原位切换“微调版 / 原作”，选择状态与文章列表保留；“正式页面”进入已采用版本。

微调内容：同排来源卡片共享名称和说明轨道；轻微收紧说明区与文章标题间距；给右侧文章稍多一点宽度，缩小真实缩略图占位；英文整词换行，手机长英文名称按字面缩小。不添加装饰模块或额外文章边框。

维护 build.py、polish.css、preview.js。build.py 只读正式文件，复制所需渲染逻辑并隔离阅读/收藏存储；字体、数据、图片及署名交互继续引用正式资源。production-hashes.json 是首次构建的188个正式文件基线，不能在后续构建中覆盖。

验收：1280px桌面两类左右分别623.6/782.8px，均等高；原作634.2/797px。同排卡片说明起点一致；MLNLP七篇中仅两篇使用已选原图，另外五篇不占图片区；内部滚动360px时页面Y保持1060。标题进入对应原文、关闭恢复焦点与来源。320/390px无横向溢出、箭头在色块内、比较控件不遮挡横幅。页面头部122.4px，与原作一致。最终截图与验收记录见当前会话 outputs/公众号原作微调预览-20261110。
